# 結帳串接 Google 試算表

網站結帳 → Google Apps Script（GAS）→ Google 試算表。

```
瀏覽器 ──POST JSON──▶ GAS 網頁應用程式 ──驗證、重算價格──▶ Orders / OrderItems 工作表
                                        └─▶（選填）寄新訂單通知信
```

## 試算表結構（`setup()` 會自動建立）

| 工作表 | 用途 |
| --- | --- |
| `Menu` | 菜單與價格的唯一依據。改價、下架（把「供應中」改成 FALSE）直接在這裡改。 |
| `Orders` | 一張訂單一列。「狀態」欄預設「新訂單」，你可以手動改成「製作中」「已完成」等。 |
| `OrderItems` | 一個品項一列，用「訂單編號」和 Orders 對應。 |

## 部署步驟（約 10 分鐘）

1. 建立一份新的 Google 試算表。
2. 選單 **擴充功能 → Apps Script**。
3. 把 `gas/Code.gs` 全部內容貼進編輯器，取代原有內容。
4. （建議）左側 **專案設定 → 勾選「在編輯器中顯示 appsscript.json」**，把 `gas/appsscript.json` 的內容貼進去。
5. 上方函式選 **setup**，按 **執行**，依畫面授權。完成後試算表會出現三張工作表。
6. （選填）**專案設定 → 指令碼屬性 → 新增** `NOTIFY_EMAIL`，值填你的信箱，之後每張新訂單都會寄通知信。
7. 右上 **部署 → 新增部署作業 → 類型選「網頁應用程式」**：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 按部署，複製 **網頁應用程式網址**（結尾是 `/exec`）。
8. 打開 `index.html`，找到 `const ORDER_ENDPOINT = '';`，把網址貼進引號內，存檔、發布。

## 之後修改程式要注意

改了 `Code.gs` 之後，要 **部署 → 管理部署作業 → 編輯 → 版本選「新版本」→ 部署**，網址不變。只按儲存不會生效。

## 安全與資料設計

- **價格不信任瀏覽器**：伺服器用 `Menu` 重算金額，與網頁送來的合計不同時拒絕下單並提示。
- **宅配規則**與網頁一致：僅限整筆皆為冷凍商品，未滿 NT$1,200 運費 NT$160。
- **重送保護**：每次結帳有唯一 `requestId`，網路逾時後重按送出不會產生重複訂單。
- **訂單編號**由伺服器產生（`GC-20261116-001`，每日重編），並用鎖避免同時下單時撞號。
- **公式注入**：訂單工作表整欄設為純文字，姓名、備註即使以 `=` 開頭也不會被當成公式。
- **蜜罐欄位** `website`：機器人填了就拒絕。
- 網頁應用程式網址「所有人可存取」是 GAS 的運作方式，所以任何人都能對它送資料；上述驗證就是用來擋亂送的資料。網址本身不是祕密，但也不需要公開張貼。

## 測試

1. 在網站下一張訂單，確認 `Orders`、`OrderItems` 各多了資料，編號為 `GC-…`。
2. 把 `Menu` 某商品的「供應中」改成 FALSE，再下單，應看到「暫停供應」提示。
3. 到 **執行項目** 頁籤可查看錯誤紀錄。
